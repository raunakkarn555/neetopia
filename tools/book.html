📖 How to Use Book Reader

A complete guide to every feature — from adding books to highlighting and OCR scanning.

1

Add Your PDF Book

Paste a GitHub Raw URL or Google Drive share link, fill in title & subject, then click + Add Book. Or click Upload PDF from Device to load from your phone/computer — no internet needed, 100% private.

2

Navigate Pages

Use the ◀ ▶ arrows on screen, the keyboard arrow keys / Page Up / Page Down, or swipe left/right on mobile. Type a page number directly in the input box to jump instantly.

3

Highlight & Underline Text

Click 🖊 Highlight to enter highlight mode, pick a color, then click & drag over any area of the page. Click U Line for underline mode. All marks are saved automatically per book.

4

Add Bookmarks & Notes

Press 🔖 Bookmark to bookmark the current page with a label. Right-click anywhere on the page to add a sticky note. View all bookmarks, highlights and notes in the ☰ Panel sidebar.

5

Scan Non-Selectable Text (OCR)

If the PDF is a scanned image, click 🔍 OCR Scan on the current page. The tool will extract all readable text and overlay it as selectable text. You can then copy-paste or search it. Requires internet (uses OCR.space API).

6

View Modes

Spread = two pages side-by-side (book feel). ↕ Scroll = all pages in one continuous scroll. 🌙 Mode cycles between Dark / Sepia (eye-friendly) / White. ⛶ Fullscreen hides everything. 🎯 Focus auto-hides the toolbar.

7

Backup Your Annotations

All highlights, bookmarks and notes live in your browser only. Use ⬇ Export Annotations regularly to save a JSON backup. Import it back anytime. Clearing browser data will erase everything — so backup often!

📥 Add a Book / PDF

Load a PDF three ways: paste a direct URL (GitHub raw / Google Drive), upload from your device, or drag-and-drop. All annotations save to your browser automatically.

How to get a GitHub Raw PDF URL:
  1. Upload your PDF to any GitHub repository.
  2. Open the file on GitHub → click the PDF filename.
  3. Click the Raw button. Copy the URL from your browser address bar.
  4. It should look like: https://raw.githubusercontent.com/user/repo/main/book.pdf
  5. Paste that URL in the field below and click Add Book.
⚠️ CORS note: GitHub raw URLs work directly. If any URL fails due to CORS, use local upload instead.
How to use Google Drive PDF:
  1. Upload your PDF to Google Drive.
  2. Right-click → Share → set to "Anyone with the link".
  3. Copy the share link: drive.google.com/file/d/FILE_ID/view
  4. Paste below — the reader auto-converts it to a direct download link.
💡 Drive PDFs may have CORS issues in some browsers. If it fails, download and use local upload.
Upload from your device:
  1. Click Upload PDF from Device below.
  2. Select any PDF — NCERT, modules, PYQ books, notes.
  3. The file loads directly in the browser — nothing is uploaded to any server.
  4. Your annotations are saved locally per book.
✅ Local upload is the most reliable method. No internet needed after uploading.
