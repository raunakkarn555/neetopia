📥 Add a Book / PDF

You can load a PDF three ways: paste a direct URL (GitHub raw / Google Drive), upload from your device, or use a Google Drive share link. All annotations save to your browser automatically.

How to get a GitHub Raw PDF URL:
  1. Upload your PDF to any GitHub repository (or use a public repo).
  2. Open the file on GitHub — click the PDF filename.
  3. Click the Raw button. Copy the URL from your browser.
  4. It should look like: https://raw.githubusercontent.com/user/repo/main/book.pdf
  5. Paste that URL in the field below and click Add Book.
⚠️ CORS note: GitHub raw URLs work directly. If any URL fails due to CORS, use local upload instead.
How to use Google Drive PDF:
  1. Upload your PDF to Google Drive.
  2. Right-click the file → Share → set to "Anyone with the link".
  3. Copy the share link. It looks like: https://drive.google.com/file/d/FILE_ID/view?usp=sharing
  4. Paste the share link below — the reader will auto-convert it to a direct download link.
  5. Format used: https://drive.google.com/uc?export=download&id=FILE_ID
💡 Drive PDFs may ask for CORS permission in some browsers. If it fails, download and use local upload.
Upload from your device:
  1. Click the Upload PDF button below.
  2. Select any PDF from your device — NCERT, modules, PYQ books, notes.
  3. The file loads directly in the browser — nothing is uploaded to any server.
  4. Your annotations (highlights, notes, bookmarks) are saved locally per book.
✅ Local upload is the most reliable method. No internet needed after uploading.
