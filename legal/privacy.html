01 · Overview

Short mein — Hum Kya Karte Hain

NEETopia ek free, ad-free educational platform hai. Hum koi personal data sell nahi karte, koi targeted ads nahi dikhate, aur koi unnecessary tracking nahi karte.

Simple rule: Jo data tumhara platform experience better banane ke liye zaroori nahi, woh hum collect hi nahi karte. Koi account, koi sign-up, koi email required nahi.

Yeh policy explain karti hai ki GitHub Pages pe hosted NEETopia platform (raunakkarn555.github.io/neetopia) ke saath tumhara interaction kaise handle hota hai.

02 · Data We Collect

Kaunsa Data Collect Hota Hai

NEETopia directly koi personally identifiable information (PII) collect nahi karta — koi naam, email, phone number, ya address nahi.

Data Type Source Purpose
Page views & navigation GitHub Pages server logs Platform uptime; automatically collected by GitHub
Browser & device type GitHub Pages server logs Anonymised; used for compatibility understanding
Study progress Your own browser (localStorage) Progress tracker functionality — stored only on your device
Theme preference Your own browser (localStorage) Remember dark/light mode choice — stored only on your device

Hum koi analytics tool (Google Analytics, Mixpanel, etc.) currently use nahi karte. Server logs GitHub ke infrastructure se hain aur unka control humare paas nahi.

03 · Local Storage

Browser Storage — Sirf Tumhara Device

NEETopia ka progress tracker aur theme toggle browser localStorage use karta hai. Yeh data:

  • Sirf tumhare device pe stored hota hai — hamari servers pe nahi
  • Hum kabhi yeh data access nahi kar sakte, transmit nahi kar sakte, ya sell nahi kar sakte
  • Browser settings mein jaake tum kabhi bhi manually delete kar sakte ho
  • Incognito/private mode mein automatically clear ho jata hai

localStorage keys used: neetopia-progress (chapter completion) aur neetopia-theme (dark/light preference).

04 · Third-Party Services

Third-Party Services Jo Hum Use Karte Hain

NEETopia kuch external services pe depend karta hai. In services ki apni privacy policies hain:

  • GitHub Pages — Platform hosting. GitHub ki privacy policy apply hoti hai (github.com/privacy). Server logs automatically GitHub collect karta hai.
  • Google Fonts — Typography (Bricolage Grotesque, DM Sans, JetBrains Mono). Font load hone pe Google ke servers se request jati hai — Google ki privacy policy apply hoti hai.
  • YouTube (embedded videos) — Kuch pages pe educational videos embed hain. Agar tum video play karte ho, YouTube/Google ki privacy policy apply hoti hai aur unke cookies set ho sakte hain.

In third-party services ke baare mein zyada jaanna ho toh unki respective privacy policies check karo. NEETopia in services ka data usage control nahi karta.

05 · Cookies

Cookies Ka Use

NEETopia khud koi tracking cookies set nahi karta. Jo cookies tumhare browser mein ho sakti hain:

  • Google Fonts cookies — Font delivery ke liye; Google ki infrastructure se aati hain
  • YouTube cookies — Sirf tab jab tum embedded video play karo; YouTube ke servers se aati hain
  • GitHub cookies — Hosting infrastructure se; platform functionality ke liye

Tum apne browser settings mein cookies disable ya delete kar sakte ho. Isse kuch third-party embedded content (jaise YouTube videos) properly load nahi hogi, lekin NEETopia ke core content pe koi effect nahi hoga.

06 · Data Sharing

Data Sharing — Hum Kisi Ko Nahi Bechte

NEETopia kisi bhi third party ko tumhara personal data sell, trade, ya rent nahi karta. Period.

  • Koi advertisers ko data nahi
  • Koi data brokers ko nahi
  • Koi marketing companies ko nahi
  • Koi partnerships for data monetisation nahi

Agar kabhi legal requirement ho (court order, etc.) toh hum GitHub ke infrastructure logs ke baare mein apni knowledge share karne ke liye bound ho sakte hain — lekin humhare paas khud personally identifiable data hai hi nahi.

07 · Your Rights

Tumhare Rights

Kyunki NEETopia koi account system ya personal data collection nahi karta, most traditional "data rights" (access, rectification, deletion) automatically satisfied hain. Tab bhi:

  • Progress data delete karna — Browser localStorage clear karo: Settings → Privacy → Clear browsing data → Cookies and site data
  • Fonts block karna — Browser extensions (uBlock Origin, etc.) se Google Fonts requests block kar sakte ho
  • YouTube tracking avoid karna — Videos sirf directly YouTube pe jake watch karo; embedded player use mat karo
  • Koi concern ho — Direct email karo: raunakkarn777@gmail.com
08 · Children's Privacy

Students Ki Privacy

NEETopia primarily 15–25 saal ke NEET aspirants ke liye banaya gaya hai. Platform specifically koi personal data collect nahi karta, isliye age verification ki zaroorat nahi hai.

Agar tum 13 saal se kam ke ho aur koi concern hai, please apne parents ya guardian se baat karo ya humein email karo. Hum younger users ki safety seriously lete hain.

Kyunki hum koi personal data collect nahi karte, students safely platform use kar sakte hain bina registration ke. Progress sirf unke apne device pe rehta hai.

09 · Policy Changes

Policy Update Hogi Toh Kya Hoga

Agar hum koi significant change karte hain jo data collection ya sharing affect kare, toh yeh page update karenge aur "Last updated" date change karenge.

Platform ka continued use updated policy se agreement maana jayega. Major changes ke liye page ka top section check karte raho.
